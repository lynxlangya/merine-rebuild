5 图标 24×24 · 描边 1.7 · currentColor

全部为单色线性图标，随文字颜色变化，不使用 emoji 作为功能图标。图标一律配文字标签；仅图标按钮必须有 aria-label 与可见焦点环。

6 实体类型

形状 + 颜色 + 汉字标 + 文字标签四重编码，不依赖颜色单一通道。图谱节点、表格芯片、引用卡、情报详情全部复用同一套形状语言。

图谱连线语义

实线：来源记录支持的关系
虚线：待核对，边标签必须写明状态
加粗实线：当前查询路径；非路径对象的图形降至 38% 不透明度，名称改用次级文字色，因此弱化后仍保持 ≥4.5:1

图谱节点示意

节点 = 形状标记 + 名称（13px/600）+ 等宽编号（10.5px）。选中态叠加品牌色描边环；路径命中仍保留实体形状与颜色，因此弱化后依然能辨认类型。

14 1366 × 768 收缩规则

收缩优先级（由先到后）

  1. 左侧导航折叠为 64px 图标栏，悬停显示名称。
  2. 筛选面板折叠为工具条上的「筛选」按钮，按钮上显示已应用条件数。
  3. 右侧详情 / 证据面板折叠，改为覆盖在画布右侧的浮层，关闭后回到原视图。
  4. 表格隐藏次要列（如「来源 / 批次」），主操作保留在表头右侧不动。
  5. 图谱画布保持可用宽度优先，永不把画布压到 480px 以下；必要时允许画布区域横向滚动。

不得牺牲的内容

  • 主操作按钮与当前状态标签。
  • 图谱画布的检索栏与视图控制。
  • AI 研判正文的引用编号与复核区入口。
  • 任务表中「成功 / 失败数」与「部分失败」标签。
  • 情报详情中的签收 / 反馈汇总与主操作。

本次交付的 HTML 已按此规则实现：窗口宽度 ≤1439px 时导航自动折叠（见 @media (max-width:1439px)），面板折叠由工具栏按钮手动控制。
