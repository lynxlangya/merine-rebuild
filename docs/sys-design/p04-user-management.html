P04 关键状态与交互

本页是全系统搜索、表格、表单与权限交互的规范来源；P03 的数据任务列表与本节共用同一套组件。

S1列表四态完整
正常 / 加载 / 空结果 / 接口失败四态共用同一容器高度，切换时不产生跳动；错误态保留查询条件并提供重新加载。
S2表单校验与错误定位
提交时先做整体校验：错误字段标红并显示原因，抽屉顶部给出错误摘要，焦点自动移到第一个错误字段（本页可直接点「保存」体验：账号留空）。
有 2 处需要修改
  • 账号：必填
  • 所属单位：必填
S3禁用：现有登录将失效
禁用不是删除。确认弹窗必须说明影响、是否保留数据、以及如何恢复。
禁用后：该账号的现有登录会话立即失效，无法再登录；已产生的研判会话与情报记录全部保留；重新启用后可继续使用原权限。
S4权限变更：会话失效并按新权限重登
权限（角色或数据范围）发生变化后，现有会话失效，用户需重新登录并按新权限访问。界面必须在保存前说明，不能只在保存后提示。
保存后该账号的现有会话将失效，须重新登录；重新登录后按新的角色与数据范围访问。
S5不可分配的权限
单位树中当前角色无权分配的节点禁用，并写明原因，而不是静默隐藏或允许勾选后失败。
