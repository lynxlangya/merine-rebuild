P01 关键状态与交互

以下状态卡片用于说明实现细节，不参与产品操作。右侧开关直接把上方画布切到「加载中 / 加载失败 / 无结果」三种状态，可逐一点开核对文案与可执行动作；切回「正常」即恢复图谱。所有卡片中的文案与主画面保持同一套演示数据。

S1选中节点与证据详情
点击节点后右侧面板切换为该对象；属性分「属性 / 来源记录 / 关联事件」三块。来源记录卡可打开核对，缺少资料的属性直接写「待核对」，不留空。

S2路径高亮
选择起点、终点与跳数上限后，命中路径加粗为品牌色实线；非路径对象的图形降至 38% 不透明度，名称改用次级文字色而不是降透明度，因此弱化后仍可读、实体形状与颜色也仍可辨认。路径侧栏逐段列出依据来源。
S3路径未命中

S5加载失败 / 加载中 / 无结果
三种画布状态都保留工具条与筛选条件：加载中用占位图形 + 当前查询范围，不用空白页；失败态给出可原样重试的动作与可展开的技术诊断；无结果直接说明「不显示推测对象，也不用其他单位数据补位」。用上方开关逐个核对。
S6达到上限 / 范围外对象
节点右下角以角标显示未加载关系数；展开后若对象不在当前筛选范围，如实说明而不悄悄隐藏。上限提示给"继续缩小范围"这一条可执行动作。
