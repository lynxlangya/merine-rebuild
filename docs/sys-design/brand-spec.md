# brand-spec.md · 海防研判工作台

**一句话系统**：以一组中性蓝灰为底、单一蓝色为品牌强调色的双主题企业工作台；用「实体形状语言」和等宽编号承载业务识别，靠背景与边界分层而非投影与渐变。

品牌来源：业务方在委托说明中直接给定 8 个起始色值与视觉定位（专业、清晰、克制、秩序感）。本文件为**实测后的最终 token**，Hex 原样保留自给定值，派生色由 OKLch 推导。

## 2. 字体栈

```css
--font-display: "HarmonyOS Sans SC","Source Han Sans SC","PingFang SC","Microsoft YaHei UI","Noto Sans SC",system-ui,sans-serif;
--font-body:    "PingFang SC","HarmonyOS Sans SC","Source Han Sans SC","Microsoft YaHei UI","Noto Sans SC",system-ui,-apple-system,sans-serif;
--font-mono:    "JetBrains Mono","SF Mono","Cascadia Mono","Roboto Mono","Noto Sans Mono",ui-monospace,SFMono-Regular,Menlo,monospace;
```

- **一个中文无衬线超家族 + 等宽数字**。这是数据密集型工作台的有意选择：中文界面里再引入第二种西文字体会造成字面比例不协调，层级交由字号、字重和颜色承担。
- 业务编号（`DEMO-P-001`）、时间、计数一律 `--font-mono` + `tabular-nums`，保证竖向可比对——这是本系统最高频的阅读动作。
- 中文标题字距恒为 `0`（禁负字距）；仅拉丁全大写加 `0.06em`。
- 中文大标题行高 `1.36`，正文 `1.75`，单行控件/表格单元 `1.5`。

## 3. 观察并固化的 5 条视觉规则

1. **顺序来自对齐，不来自装饰。** 全站只用 4/8 间距体系与 6px 圆角；分层依靠 `--surface` / `--bg` 的明度差与 1px 边界，不叠投影，不使用渐变。
2. **一个强调色，每屏最多两处可见。** 蓝色只出现在主操作、当前选项卡下划线、焦点环、选中态图标。实体分类与状态另立独立色系，绝不借用品牌蓝。
3. **实体形状语言是全系统唯一的"记号"。** 人员=圆形、船舶=圆角矩形、地点=方形、事件=菱形，这个形状在表格芯片、AI 引用卡、情报详情、图例中重复出现——它同时表达类型，也让这套界面在截图里可被辨认。（同时用形状+颜色+汉字标（人/船/港/事）+文字标签四重编码，不依赖单一颜色。）
4. **关系必须写明依据。** 图谱实线=来源记录支持，虚线=待核对且边标签必须写出状态；AI 正文的每个引用编号都能打开对应演示片段。"没有依据的内容不生成伪引用"是视觉规则，不是文案规则。
5. **风险结论不出现在视觉语言里。** 界面只用"记录关联""待核对""来源缺口"这类记录层表述，不使用风险等级、嫌疑度等色阶与图形。

## 4. 已知未验证项

- 上述对比度为**静态色值计算**（WCAG 2.2 相对亮度公式），非在真实屏幕与浏览器上取样。
- 未测：字体实际渲染字面率、图表在色觉障碍模拟下的可区分度、暗黑模式在低亮度显示器上的主观可读性。
- 因此本设计**不宣称已完成无障碍验收**，只声明：已列出的关键颜色组合通过了对应门槛（正文 4.5:1 / 控件与图形 3:1）。
