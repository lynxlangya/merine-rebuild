# 任务处置模块建设思路

总队业务沟通简稿 · 2026-09-27

本模块围绕总队交办任务，贯通“下达、承接、办理、反馈、办结”全过程，让总队能够看清：**任务交给了谁、现在谁负责、办理到哪一步、是否按期、最终是什么结果。**

## 一、一项任务如何办理

**总队明确要求和期限 → 支队承接并组织办理 → 按需安排直属大队落实 → 支队汇总反馈 → 总队形成总体结论并办结。**

总队可以将同一项任务同时下达给多个直属支队，各支队分别承担责任、提交答复。支队安排大队办理后，仍负责汇总本支队的情况；下级办理结束后，支队还需提交自己的正式答复。

设计中重点把握三件事：

- **责任明确。** 以单位为责任主体，同时记录具体经办人和操作时间。向下安排工作后，上级单位仍承担汇总责任。
- **过程可查。** 保留承接、进展、退回、交接、答复等经过，能够追溯责任变化及其原因。
- **结果说清。** 正式答复区分“目标达成、经核查未发现、部分完成、无法核实、转出辖区”，同时说明已做工作和结论。办理结束与实际成效分别呈现，便于总队判断是否还需后续安排。

各项办理责任都已答复，或按规则撤回后，任务进入“待办结”。由总队填写总体结论，完成整项任务的办结。

## 二、特殊情况如何处理

| 场景                             | 处理方式                                                                                                 | 总队可以掌握什么                                         |
| -------------------------------- | -------------------------------------------------------------------------------------------------------- | -------------------------------------------------------- |
| 任务派错单位、职责不符或要求不清 | 支队在承接前说明原因退回；总队在期限允许时重新派发，或说明原因撤回该项办理要求                           | 退回原因、处理决定及后续去向，退回事项仍有人负责处理     |
| 办理中需要交接给另一支队         | 原支队说明原因、已做工作和剩余事项；目标支队同意并提出所需办理时间；总队批准并明确新期限后，责任正式转移 | 交接必要性、双方意见、新期限；批准前仍由原支队负责       |
| 大队核查发现事项涉及其他辖区     | 大队如实反馈核查结果和建议，由支队决定是否另行下达后续任务，并重新明确期限                               | 已查明的情况、尚需办理的事项，以及后续任务与原结果的联系 |

交接时保留原承办单位的办理经过和原期限。确需延长整项任务期限的，由总队在批准交接时说明理由；其他支队已有的办理期限不随之自动延长。

## 三、总队重点看哪些信息

针对总队发起的每项任务，页面重点呈现以下内容：

| 关注点           | 重点查看的信息                                               |
| ---------------- | ------------------------------------------------------------ |
| 责任是否落实     | 各单位是否承接、当前由谁办理、退回或交接事项是否待处理       |
| 进度是否正常     | 最新办理进展、各单位办理期限、答复时间与逾期情况             |
| 结果是否清楚     | 各单位正式答复、结果类型、未完成事项及建议后续单位           |
| 是否需要总队处理 | 待决定的支队交接、退回后的重新安排，以及待填写总体结论的任务 |
| 过程能否复核     | 经办人、关键时间、退回和交接原因、原期限与批准后的期限       |

汇总进度时，以总队下达的各项办理责任为口径；支队下属大队的办理情况可以展开查看，避免同一项责任在支队、大队两级重复计数。

## 四、用一个例子说明

总队将一项核查任务交给甲、乙两个支队。甲支队组织大队核查后，反馈“经核查未发现”，并提交办理说明；乙支队发现需要丙支队接续办理，提出交接申请。

丙支队同意并说明所需时间后，总队决定是否批准，批准时明确新期限。丙支队完成答复后，总队汇总两项办理责任的结果，填写总体结论并办结。全过程保留乙、丙之间的责任变化和办理记录。

## 五、当前范围与沟通重点

当前首版已实现上述主要办理流程，下一步结合总队实际场景开展页面演示和业务验收。附件、自动催办推送、统计报表及导出尚未纳入本次实现；现有期限与逾期展示可供人工跟进使用。

本次汇报建议重点核对：**总队、支队、大队的职责分工是否符合实际；支队交接与期限确定方式是否适用；各单位答复和总队总体结论需要明确哪些内容。**
